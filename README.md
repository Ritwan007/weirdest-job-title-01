# Weirdest Job Title: Blind Judge Showdown

Entry program for the make.fun competition
`u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922`.

`main.py` writes a single job title (44 characters) to `/output/entry.txt`:

> Professional Mourner for Strangers' Goldfish

A real-sounding job (professional mourner) with one gloriously specific,
funny twist (for strangers' goldfish) — weird, specific, and readable at a
glance, per the published judge brief.

Run: `python3 main.py`
